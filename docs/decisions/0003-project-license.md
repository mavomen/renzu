# ADR-0003: Project license

## Status
Accepted

## Decision
The Renzu Observability project is licensed under the MIT License, as recorded in `LICENSE`.

## Context
F-001 reference repository reconnaissance confirmed an MIT-licensed reference implementation (MIT, Copyright 2026 Mava - Mani Nava). Reusing the same license keeps the project simple, permissive, and consistent with the inspected reference.

## Consequences
- The `LICENSE` file is committed at the repository root.
- The license choice is recorded here and referenced from `docs/ARCHITECTURE.md` §9.
- No contributor license agreement or dual-licensing is introduced at this stage.
